# X Score Dashboard

A Next.js 14 dashboard for tracking X (Twitter) account engagement scores using the Synergy Drive Systems V3 Design System (Technical Industrial Minimalism).

## What This Is

A static-first web app that displays scoring data for the **@tgtanalytics** X account. It reads from a single `public/data.json` file that is generated by the scraper pipeline. The app deploys to Vercel via GitHub — every push to the main branch triggers an automatic rebuild and deploy.

## Design System

**V3 — Technical Industrial Minimalism**

- No shadows, no gradients, no border-radius (max 4px)
- Bento Box layout: containers with thin borders, generous padding
- Inter (sans) + Roboto Mono (data/labels)
- Orange accent (#FF5A1F) only for CTAs and important values
- Uppercase monospace metadata (10-12px, letter-spacing 0.05em)

## Data Pipeline

```
x_scraper.py          → scrapes X profile + recent posts
    ↓
score_calculator.py   → scores each post using weighted signals
    ↓
export_web.py         → merges scraper output + adds ghost analysis
    ↓
x-score-web/public/data.json
    ↓
git push              → GitHub triggers Vercel auto-deploy
    ↓
Live dashboard        → https://x-score-dashboard.vercel.app
```

### Signal Weights

| Signal      | Weight  | Description                        |
|-------------|---------|------------------------------------|
| Replies     | 5.0x    | Highest — indicates conversation   |
| Reposts     | 1.0x    | Amplification beyond your audience |
| Likes       | 0.5x    | Light engagement signal            |
| Views       | 0.05x   | Dwell time proxy                   |
| Bookmarks   | 0.5x    | Save intent (high quality)         |

## How to Update the Data

1. Run the scraper pipeline:
   ```bash
   cd C:\Users\TGT NY\.openclaw\workspace\x-dashboard
   python run_dashboard.py
   ```

2. Export to web format:
   ```bash
   python export_web.py
   ```
   This merges `posts.json`, `scores.json`, `account.json` into `data.json` and copies it to `x-score-web/public/data.json`.

3. Commit and push:
   ```bash
   cd C:\Users\TGT NY\.openclaw\workspace\x-score-web
   git add public/data.json
   git commit -m "Update dashboard data — $(date)"
   git push origin main
   ```

4. Vercel auto-deploys on push. Live in ~30 seconds.

## How to Deploy to Vercel

### First-time setup

1. Push the repo to GitHub:
   ```bash
   cd x-score-web
   git init
   git add .
   git commit -m "X Score Dashboard — initial release"
   git remote add origin https://github.com/<your-user>/x-score-dashboard.git
   git push -u origin main
   ```

2. Go to [vercel.com](https://vercel.com) → New Project → Import the GitHub repo

3. Framework preset: **Next.js** (auto-detected)

4. Click **Deploy**. Done.

### Subsequent updates

Just push to `main`. Vercel rebuilds automatically.
